BoltaNote: a web page, not an app

  • Reads the live camera 4 times a second
  • Speaks the value in Urdu or English
  • Stays silent when unsure: a wrong amount is worse than none
  • Works offline once loaded, any phone browser
  • Vibration code and screen-reader support
پانچ سو روپے
"Five hundred rupees"

Data: 3,611 real phone photos, 15 classes

  • Kaggle Pakistan Image Currency Dataset (CC0)
  • 7 notes × front and back = 14 classes
  • + "no note": 280 photos + 1,000 everyday Imagenette photos
  • Folded, in hand, half visible, on bedsheets
  • Split 70 / 15 / 15, near-copies kept together

Before trusting any number:
are the test photos really new?

339 / 402
test photos in a second public dataset are near-copies of the first
  • Perceptual hash of every photo (64 bits)
  • Photos within 8 bits = the same photo
  • Only 63 genuinely new photos left
  • Without this check: near-perfect, and meaningless

When to speak, and when to stay silent

  • Validation photos look too easy: any threshold seems safe
  • So: calibrate on a stress test, validation photos × 4 augmentations
  • Threshold 0.68: at most 1 wrong value in 500 there
  • Plus: same answer in 3 frames in a row

Limits, and what's next

Limits
  • A few physical notes per value in training
  • 2005–2008 designs; the new series needs new photos
  • One note at a time; not a counterfeit detector
Next
  • Worn, torn and taped notes
  • Count a whole handful of notes
  • Test with blind users
